# 🧁 Confeitaria Doce Sabor — Website & Caderno de Pesquisa

> Projeto desenvolvido como Atividade de Pesquisa (Não Presencial) na Unidade Curricular de **Linguagem de Marcação** do curso Técnico em Desenvolvimento de Sistemas — Escola SENAI "A. Jacob Lafer".

---

## 📌 Sobre o Projeto

A **Doce Sabor** é uma confeitaria de bairro gerenciada pela Dona Márcia. Historicamente, os pedidos chegavam de forma descentralizada por mensagens de texto, ocasionando perda de informações. 

Este projeto consiste no desenvolvimento de uma página web institucional e funcional para a loja, contemplando:
* Cardápio responsivo de produtos;
* Seção de perguntas frequentes (FAQ) interativa;
* Mapa de localização incorporado;
* Formulário completo de encomendas de clientes.

---

## 🎯 Capacidades Trabalhadas

* **Capacidade Técnica 3:** Utilizar linguagem de marcação para desenvolvimento de páginas web.
* **Capacidade Técnica 4:** Codificar leiautes de página web.
* **Capacidade Técnica 5:** Utilizar semântica de linguagem de marcação conforme normas de acessibilidade.
* **Capacidade Técnica 6:** Elaborar formulários de página web com validações nativas.
* **Capacidade Técnica 7:** Aplicar técnicas avançadas de estilização CSS (*Glassmorphism*, Grid, Transições e Media Queries).
* **Capacidades Socioemocionais:** Autogestão, pensamento analítico e autonomia.
